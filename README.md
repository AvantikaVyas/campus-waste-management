# CampusCare — Campus Waste Management System:
A centralized campus waste management platform designed to make waste collection smarter, faster, and more efficient.
CampusCare allows students to report waste-related issues across campus while providing staff with a dedicated portal to monitor reports, manage dustbins, and coordinate waste collection.

## Features:
### Student Portal:
- Report Waste Issues: Report overflowing dustbins, unclean areas, or locations that need additional dustbins.
- Location-Based Reporting: Specify the exact campus location of a waste-related issue.
- Track Reports: Monitor the status of submitted complaints.
- Real-Time Updates: Stay informed about the progress of reported issues.

### Staff Portal:
- Centralized Dashboard: View and manage waste-related reports.
- Report Management: Review reports and update their status.
- Dustbin Management: Monitor dustbin conditions and identify locations requiring attention.
- Location-Based Monitoring: Identify waste management hotspots across campus.
